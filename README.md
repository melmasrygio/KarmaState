# KarmaState

KarmaState enables real-time, event-driven orchestration of distributed systems, leveraging auto-scaling and predictive-maintenance capabilities via a decentralized agent platform.

KarmaState is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/KarmaState.git`
2. `cd KarmaState`
3. Install in editable mode: `pip install -e .`

## Configuration

KarmaState is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
